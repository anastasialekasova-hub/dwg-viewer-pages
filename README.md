# DWG Viewer — pages

Welcome, uninstall and feedback pages for the DWG Viewer Chrome extension, served via GitHub Pages.

- `/welcome/` — opens once after installation
- `/uninstall/` — feedback form, opens when the extension is removed
- `/feedback/` — opens for 1–3 star ratings from the in-viewer rating prompt
- Privacy policy: https://pinwisp.com/dwg-viewer/privacy/ (not hosted in this repo)

Illustrations on the welcome page are renders of the approved design artboards;
real viewer screenshots can replace them later without layout changes.

Addresses must stay in sync with `WELCOME_URL` / `UNINSTALL_URL` / `FEEDBACK_URL`
in the extension's `src/lib/config.js`.
